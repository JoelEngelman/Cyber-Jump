# CYBER//JUMP ⚡

A fast, neon-soaked scrolling platformer set in a dystopian cyberpunk city.

## Features

- Procedurally generated scrolling city/platform layout
- Neon cyberpunk skyline, lighting, particles and scanline effects
- Responsive movement and jumping
- Energy-powered dash
- Combo multiplier system
- Collectible credits and data shards
- Enemy security drones you can stomp
- Side-quest system and reward notifications
- HUD with distance, score, credits, combo and energy
- Game-over/reboot loop so the run keeps going
- No build tools or dependencies required — it is a single HTML game

## Controls

- **A / D** or **Arrow Keys** — move
- **Space / W / Up** — jump
- **Shift** — dash
- **Esc** — pause

## Run it

Open `index.html` in a browser, or enable GitHub Pages for the repository and publish from the `main` branch.
